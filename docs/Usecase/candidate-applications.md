## Candidate Applications Module

The Candidate Applications module streamlines the electoral filing process by providing secure portals for partylist registration, candidate application submission, and SEB administrative review. It automates eligibility verification against SEB Code criteria, manages partylist affiliation workflows, and ensures transparent status tracking throughout the candidacy approval pipeline.

### Use Case Scenarios

- [Register Partylist](/docs/Usecase/Candidate%20Applications/register-partylist.md)
- [File Certificate of Candidacy (COC)](/docs/Usecase/Candidate%20Applications/file-certificate-of-candidacy.md)
- [SEB Application Review & Status Tracking](/docs/Usecase/Candidate%20Applications/application-review-status-tracking.md)
- [Candidate Portal Authentication & Status Tracking](/docs/Usecase/Candidate%20Applications/candidate-portal-authentication.md)
- [Partylist Affiliation Management](/docs/Usecase/Candidate%20Applications/partylist-affiliation-management.md)

---

### Key Features

- **Partylist Registration**: Formal establishment of political coalitions with duplicate prevention
- **Automated Eligibility**: Real-time validation against SEB Code criteria (enrollment, track record)
- **Document Management**: Secure upload and storage of required candidacy documents
- **OAuth Authentication**: Google-based institutional email verification for portal access
- **Affiliation Control**: Party leader approval workflow to prevent unauthorized affiliations
- **Status Transparency**: Real-time tracking dashboard for candidate application progress
